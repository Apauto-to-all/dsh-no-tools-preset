# DSH 无工具预设（No-Tools Preset）

**简体中文** · [English](README.en.md)

一个"什么都不给"的 DSH agent 预设：禁掉所有工具——不能执行代码、不能读写文件、不能上网，只留下模型自己的推理。适合让模型纯想清楚一件事再回答，也适合做模型能力对照测试的"裸奔基线"。

## 它做什么

- **工具数归零**。预设行在预设 scope 里 `ctx.tools.restrict({deny})` 挡掉全局层注册的全部工具（第三方插件注册的也一起挡），宿主内置工具行本就不在该预设内加载
- **晚到的也挡**。监听 `tools/change` 事件，晚于预设激活的插件注册的工具同样被禁
- **只留人格**。预设本身除 persona 外不注册任何工具，预设下 agent 工具数为 0

## 安装

```bash
dsh plugin --profile web add dsh-no-tools-preset
```

桌面版在「插件」页搜索 `dsh-no-tools-preset` 安装。装完在模型菜单/预设列表选「无工具」即用。

## 已知限制

- 无工具意味着模型不能查证任何事实，答案完全靠训练记忆——适合推理与创作，不适合需要最新信息的任务
- 本预设挡的是**工具**；模型仍可正常对话与思考
